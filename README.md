# 🍘 Win Snack Mobile Commerce Application

An Android-based mobile commerce application developed for the **Win Snack** brand, featuring an **AI-powered chatbot** to provide personalized product recommendations and enhance customer engagement.

This project was developed as the **Final Project** for the **Mobile Commerce Development** course at the **University of Economics and Law (VNU-HCM)**.

---

## 📱 Overview

Win Snack is an e-commerce application designed to improve the online shopping experience for customers purchasing Vietnamese rice paper products.

The application combines traditional e-commerce features with an intelligent chatbot powered by **Google Gemini API**, enabling users to:

- Browse and search products
- Receive personalized product recommendations
- Ask questions about products, promotions, and ordering
- Manage shopping carts and orders
- Complete purchases through multiple payment methods

An accompanying **Admin Web Dashboard** allows administrators to manage products, orders, promotions, blogs, and customer information.

## 🏗️ System Architecture

The application follows a **Client–Server Architecture** consisting of:

- Android Client
- Firebase Backend
- Gemini API
- Dialogflow
- Admin Dashboard

The chatbot combines:

- Rule-based responses for common questions
- AI-generated responses for complex conversations
